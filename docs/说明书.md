# HostMonitor - 系统使用说明书

## 系统简介

HostMonitor 是一款主机监控系统，用于实时监控主机的运行状态、性能指标、进程信息，并支持远程屏幕查看、告警通知、黑白名单规则等功能。

系统采用 B/S 架构，用户通过浏览器访问系统，被监控主机上需部署客户端程序。

> **本次更新**：系统设置全面完善，新增邮件通知、组级别设置覆盖、数据自动清理、客户端配置热推送等功能。

***

## 角色说明

系统定义了三种角色，不同角色拥有不同的操作权限：

| 角色 | 说明 |
|------|------|
| 超级管理员 | 拥有系统所有权限，可管理所有用户、分组、主机、告警、通知和系统设置 |
| 组管理员 | 管理本组内的用户和主机，可向组内发送通知，可管理本组进程规则和部分设置 |
| 普通用户 | 查看仪表盘、性能指标、接收告警通知 |

### 各角色可访问的功能

| 功能 | 超级管理员 | 组管理员 | 普通用户 |
|------|:---:|:---:|:---:|
| 仪表盘 | ✅ | ✅ | ✅ |
| 主机管理 | ✅ | ✅（本组） | ✅（本人） |
| 告警中心 | ✅ | ✅（本组） | ✅（本人） |
| 进程管理 | ✅ | ✅ | ❌ |
| 用户管理 | ✅ | ✅（本组） | ❌ |
| 组织管理 | ✅ | ❌ | ❌ |
| 通知管理 | ✅ | ✅（本组） | ✅（接收） |
| 系统设置（全局） | ✅ | ❌ | ❌ |
| 系统设置（客户端/告警） | ✅ | ✅（本组） | ❌ |

## 快速开始

### 注册与登录

1. 打开浏览器，访问系统地址（默认 `http://localhost:5173`）
2. 在登录页面点击"注册账号"
3. 填写用户名、邮箱、密码完成注册（注册后自动成为普通用户）
4. 使用注册的账号登录系统
5. 初始超级管理员账号：`admin` / `123456`

### 监控一台主机

1. 登录系统后，进入用户管理页面，找到对应的账号，复制 Agent Key
2. 将 Agent Key 配置到被监控主机上的客户端程序中（修改 `application.properties` 中的 `agent.key` 字段）
3. 启动客户端程序，客户端将自动连接服务端并开始上报数据，同时自动拉取服务端下发的配置
4. 在主机管理页面即可看到该主机，点击进入详情页可查看性能指标、进程列表等

## 功能使用说明

### 1. 仪表盘

仪表盘是系统的首页，展示系统概览信息：

- **在线主机数**：当前在线的主机数量
- **未处理告警**：当前未处理的告警数量
- **最近告警摘要**：最近产生的告警记录

### 2. 主机管理

主机管理页面展示所有有权限查看的主机列表。

**查看主机列表**：

- 支持按关键词搜索主机（主机名、IP 地址）
- 支持按在线状态筛选（在线/离线）
- 列表显示主机名、IP、操作系统、状态、最后心跳时间等信息

**查看主机详情**：

- 点击主机进入详情页，可查看主机基本信息和最新性能指标
- **性能指标**：展示 CPU 使用率、内存使用率、磁盘使用率的折线图，支持切换时间范围（可在展示设置中配置默认时间范围）
- **进程列表**：展示主机当前运行的进程列表，标注黑白名单违规状态，点击刷新按钮获取最新数据
- **进程规则**：查看和配置该主机所属分组的黑白名单规则

**屏幕监控**：

- 点击"监控"按钮进入屏幕监控页面，可实时查看主机屏幕画面
- 画面比例 16:9 自适应，使用双缓冲渲染减少闪烁
- 关闭页面后客户端自动停止截屏，节省资源

**删除主机**：

- 管理员可删除主机，删除后关联的性能指标数据也会一并清除

### 3. 告警中心

告警中心展示系统产生的告警记录。

**告警类型**：

- **进程告警**：检测到黑名单进程运行，或白名单进程未运行时触发
- **性能告警**：CPU/内存/磁盘使用率超过设定阈值时触发

**告警操作**：

- 支持按告警类型、处理状态筛选
- 点击"标记已处理"可将告警标记为已处理状态
- 告警产生时系统自动发送通知给主机所属用户和组管理员
- 如已配置邮件通知，告警会自动发送邮件到相关用户邮箱

### 4. 进程管理

进程管理页面位于系统设置 → 告警设置标签页中，用于配置进程的黑白名单规则（仅超级管理员和组管理员可访问）。

**黑名单规则**：指定不允许运行的进程名，当检测到该进程运行时触发告警

**白名单规则**：指定必须运行的进程名，当检测到该进程未运行时触发告警

**操作说明**：

- 规则按分组配置，每个分组可独立设置黑白名单
- 超级管理员可管理所有分组的规则，组管理员仅管理本组规则
- 支持按进程名搜索、按分组筛选、按规则类型筛选
- 添加规则时选择分组、规则类型（黑名单/白名单），填写进程名和描述

### 5. 用户管理

用户管理页面用于管理系统用户（仅超级管理员和组管理员可访问）。

**查看用户列表**：

- 支持按关键词搜索、按角色筛选、按所属分组筛选
- 列表显示用户名、邮箱、角色、所属分组、状态等信息

**编辑用户**：

- 点击编辑按钮可修改用户邮箱、密码、状态、所属分组、角色
- 角色分配规则：
  - 超级管理员角色不可被分配，仅通过系统初始化产生
  - 分配组管理员角色时，目标用户必须已加入分组，且该分组当前无管理员
  - 组管理员被移出分组时自动降级为普通用户

**Agent Key 管理**：

- 编辑弹窗中展示当前用户的 Agent Key（脱敏展示，点击即可复制完整密钥）
- 重置按钮：重置前需确认，重置后自动断开该用户客户端的连接

**删除用户**：

- 超级管理员不可被删除

### 6. 组织管理

组织管理页面用于管理系统分组（仅超级管理员可访问）。

**分组操作**：

- 创建分组：填写分组名称和描述
- 编辑分组：修改分组名称和描述
- 删除分组：删除时自动移出所有成员并撤销管理员身份

**成员管理**：

- 添加成员：从用户列表中选择用户加入分组（超级管理员不可加入分组）
- 移除成员：将用户移出分组（组管理员被移出时自动降级为普通用户）

**管理员管理**：

- 指定管理员：从分组成员中指定一名用户为组管理员（每组仅一名）
- 撤销管理员：撤销组管理员身份，降级为普通用户

### 7. 通知管理

通知管理页面用于查看和发送通知。

**查看通知**：

- 顶部铃铛图标实时显示未读通知数量
- 通知列表支持分页查看，可标记单条已读或全部已读
- 可删除不需要的通知
- 过期通知根据系统设置中的"通知保留天数"自动清理

**发送通知**：

- 超级管理员：可发送全体通知、指定分组通知、指定用户通知
- 组管理员：可向本组发送通知
- 系统自动发送告警通知（发送者显示为"系统"）

### 8. 系统设置

系统设置页面包含五个标签页，根据角色不同可见不同内容。

#### 8.1 常规设置（仅超级管理员）

| 设置项 | 说明 |
|--------|------|
| 系统名称 | 显示在侧边栏顶部和浏览器标题栏 |
| 会话超时时间 | 登录会话过期时间（1/2/4/8/24小时），超时后需重新登录 |
| 数据保留天数 | 性能指标和进程数据的保留期限，过期自动清理（默认2天） |

#### 8.2 展示设置（仅超级管理员）

| 设置项 | 说明 |
|--------|------|
| 指标刷新间隔 | 主机详情页性能指标自动刷新频率（5秒/10秒/30秒/关闭） |
| 默认指标时间范围 | 进入主机详情时折线图默认展示的时间范围（1h/6h/24h/7d） |
| 主机列表默认排序 | 主机列表的默认排序方式（在线优先/主机名/CPU/内存） |

> 展示设置为浏览器本地存储，不同设备可独立配置。

#### 8.3 客户端设置（超级管理员/组管理员）

配置保存后自动推送给在线客户端，无需重启；**离线客户端下次连接时自动拉取**。

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 指标采集间隔 | 上报 HOST_METRIC 的间隔 | 5000 ms |
| 进程采集间隔 | 上报 PROCESS_LIST 的间隔 | 15000 ms |
| 屏幕推流帧率 | 屏幕监控的帧率 | 5 FPS |
| 屏幕推流画质 | JPEG 压缩质量（0.1~1.0） | 0.5 |
| 进程 CPU 变化阈值 | 增量上报时 CPU 变化超过此值才上报 | 1.0% |
| 心跳超时时间 | 服务端多久未收到心跳则断开连接 | 60 秒 |
| 离线判定阈值 | 超过该时间未收到心跳判定主机离线 | 60 秒 |

> 组管理员只能修改本组的客户端设置，修改后会覆盖全局配置。

#### 8.4 通知设置（仅超级管理员）

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 通知保留天数 | 过期通知自动清理 | 30 天 |

**邮件通知**：

| 设置项 | 说明 |
|--------|------|
| 启用邮件通知 | 开启后告警发生时自动发送邮件 |
| SMTP 服务器 | 邮件服务器地址，如 `smtp.qq.com` |
| SMTP 端口 | 邮件服务器端口（默认 465，SSL） |
| 发件人地址 | 发送告警邮件的邮箱地址 |
| 授权码 | 邮箱服务商提供的 SMTP 授权码，非登录密码 |
| 发送测试邮件 | 配置完成后发送测试邮件验证配置是否正确 |

#### 8.5 告警设置（超级管理员/组管理员）

**进程告警**：

| 设置项 | 说明 |
|--------|------|
| 启用进程告警 | 开启后检测黑白名单规则触发告警 |
| 进程规则管理 | 在页面内直接添加/删除/搜索黑白名单规则 |

**性能告警**：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用性能告警 | 开启后 CPU/内存/磁盘超阈值触发告警 | 开启 |
| CPU 使用率阈值 | 超此值触发告警 | 90% |
| 内存使用率阈值 | 超此值触发告警 | 90% |
| 磁盘使用率阈值 | 超此值触发告警 | 90% |

**通用设置**：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 告警去重间隔 | 同一主机同一类型告警的最小间隔 | 30 分钟 |

> 组管理员可为本组单独设置告警阈值和去重间隔，覆盖全局配置。

## 数据清理机制

系统自动清理过期数据：

| 数据类型 | 默认保留 | 可配置 |
|----------|----------|--------|
| 性能指标（host_metric） | 2 天 | 系统设置 → 数据保留天数 |
| 进程数据（host_process） | 2 天 | 系统设置 → 数据保留天数 |
| 通知（notification） | 30 天 | 系统设置 → 通知保留天数 |

清理任务每天凌晨 3:00 自动执行。

## 常见问题

**Q：客户端启动后主机列表中看不到主机？**

检查客户端配置中的 `socket.host` 和 `socket.port` 是否正确指向服务端地址（默认 TCP 端口 10801），以及 `agent.key` 是否与用户管理页面中的 Agent Key 一致。

**Q：主机显示在线但无法查看屏幕监控？**

确认客户端配置中 `screen.enabled=true`，且 UDP 端口（默认 10802）未被防火墙阻挡。

**Q：进程列表中看不到完整进程？**

点击刷新按钮获取最新进程快照。部分低 CPU 占用的系统进程可能被过滤，可在客户端设置中调整进程 CPU 变化阈值。

**Q：告警没有收到通知？**

1. 确认告警设置中对应类型的开关已开启
2. 确认进程规则（黑白名单）已正确配置
3. 检查通知铃铛中是否有未读通知
4. 如需邮件通知，请检查邮件配置是否完成并通过测试

**Q：Agent Key 重置后客户端无法连接？**

Agent Key 重置后，旧密钥立即失效，客户端连接会被断开。需要将新的 Agent Key 重新配置到客户端的 `application.properties` 中，然后重启客户端。

**Q：修改了客户端设置但没生效？**

在线客户端会实时收到配置推送，无需重启。如果客户端当时离线，下次连接并认证后会自动拉取最新配置。

**Q：组管理员可以看到哪些系统设置？**

组管理员可以查看和修改本组的客户端设置和告警设置（包括性能阈值、告警开关、去重间隔），但无法修改全局常规设置和展示设置。
